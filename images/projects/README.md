# Project thumbnails

Drop project thumbnail images here. The Projects page (`_pages/projects.html`)
references the filenames below — when a file exists, it appears on the right
side of the matching project card; missing files are hidden automatically.

| Filename | Project |
|---|---|
| `mobility-synthesis.png` | AI-Based Individual-Level Mobility Data Synthesizing |
| `crowd-congestion.png` | Measuring Congestion of Gathering Occasions |
| `open-mobility-platform.png` | Real-Time Open Mobility Service Platform |
| `deidentification.png` | De-identification Technologies for Mobility Data |
| `dna-graduate-program.png` | Graduate Program for Convergence Technology of D/N/A |
| `hazardous-driving.png` | Hazardous Driving Indicators (Hyundai) |
| `av-validation.png` | Validating Autonomous Driving Services (Laws/Regulations) |
| `parking-legislation.png` | Mechanical Parking Lot Legislation |

Recommended size: roughly square, 260×260 px or larger (displayed at 130 px wide).
`.png`, `.jpg`, `.webp` all work — just keep the filename (or update the `src` in
`projects.html` accordingly).
